# Использование chi как HTTP router

## Статус

Принято

## Контекст

Требуется лёгкий и идиоматичный HTTP router без фреймворка.

## Решение

Использовать `chi` для маршрутизации HTTP-запросов.

## Последствия

- Минимальный overhead
- Совместимость со стандартным `net/http`
- Простота тестирования

## Альтернативы

- стандартный mux
- gin
- echo
