# Использование fx для dependency injection

## Статус

Принято

## Контекст

Необходимо управлять созданием компонентов и их жизненным циклом без использования глобального состояния и скрытых инициализаций.

## Решение

Использовать `go.uber.org/fx` для dependency injection и lifecycle management.

## Последствия

- Явное описание зависимостей
- Централизованный контроль старта и остановки приложения
- Небольшой порог входа для новых контрибьюторов

## Альтернативы

- Ручная инициализация зависимостей
- google/wire
