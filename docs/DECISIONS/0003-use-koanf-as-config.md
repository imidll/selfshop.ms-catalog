# Использование koanf для конфигурации

## Статус

Принято

## Контекст

Требуется гибкая система конфигурации с поддержкой нескольких источников и валидацией на старте приложения. Так же, возможность переопределять значения из разных источников.

## Решение

Использовать `koanf` для загрузки и агрегации конфигурации.

## Последствия

- Поддержка файлов и переменных окружения
- Конфигурация задаётся извне
- Возможность ранней проверки корректности конфигурации

## Альтернативы

- viper
- Ручной парсинг конфигурации
