# Использование zap для логирования

## Статус

Принято

## Контекст

Необходимо структурированное логирование с минимальным overhead и возможностью быстрой конфигурации уровней логов.

## Решение

Использовать `zap` как основной логгер приложения.

## Последствия

- Высокая производительность
- Структурированные логи
- Явное управление уровнями логирования

## Альтернативы

- zerolog
- logrus
- стандартный log/slog
